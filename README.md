# vignette-umap

Vignette on implementing Uniform Manifold Approximation and Projection (UMAP) for visualization and non-linear dimensionality reduction on high dimensional data; created as a class project for PSTAT197A in Fall 2026*.*

### Abstract

UMAP is a tool for both visualization of high dimensional data and non-linear feature extraction. This vignette demonstrates both use cases using the `uwot` library in R. We explore how UMAP works and the benefits it has before going through two worked examples:

- Visualizing multi-dimensional customer data in 2D

- Running feature extraction on vectorized webpage text data as a preprocessing step before classification
